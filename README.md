## 🔧 Setup

1. Clone the repository
2. Create a file `.env` based in `.env.example`
3. Insert your OpenAI API KEY in `.env`:
4. Active the VENV and install the requirements:
```bash
pip install -r requirements.txt
```

```bash
ppython starting.py
```
